# Portfolio Website

I built a personal portfolio website using HTML and CSS with About, Skills, Projects and Contact sections.
The code is pushed to GitHub and deployed on Netlify by importing the repository.
The live site runs over HTTPS: https://profound-manatee-20e109.netlify.app
